# 繁體中文商品文案

## Name

Authenticator-For-2FA

## Short description

動態驗證碼、可選介面鎖與加密備份。

## Full description

使用 Authenticator-For-2FA，在瀏覽器中產生和管理雙重驗證所需的動態驗證碼。

• 在裝置上產生 TOTP、HOTP 和 Steam 驗證碼。
• 手動新增帳戶，或匯入 OTP 連結、QR 碼圖片、遷移 QR 碼及支援的備份。
• 授權後，從選定網頁區域、螢幕或相機掃描 QR 碼。
• 搜尋、加入最愛和調整帳戶順序，點擊驗證碼即可複製。
• 可選填入指定驗證碼欄位，不會提交表單。啟用輸入欄位選單時請求網站存取權限。
• 匯出密碼保護的加密備份，也可明確選擇明文格式。
• 可選使用獨立復原金鑰，透過瀏覽器同步服務同步加密帳戶副本；各裝置需使用同一瀏覽器同步帳戶。
• 可選設定介面密碼。通行密鑰依賴瀏覽器和系統支援；支援的 Mac 使用 Touch ID 時需先設定本機輔助程式。

請注意：介面鎖不會加密本機帳戶密鑰及本機同步復原金鑰，初始狀態不啟用密碼保護。請保護瀏覽器設定檔，保留經過驗證的備份及各服務的備用復原方式。

QR 碼使用內建程式碼在本機解碼，無廣告或使用分析。可選的時間校準會在網站授權後連線至 Google；可選的加密同步使用瀏覽器廠商服務；網頁填入會把選定驗證碼傳送到目標網站。資料處理和刪除方式（包括保留的帳戶刪除紀錄）請見隱私權政策。
