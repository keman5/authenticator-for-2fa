## 名称

Authenticator-For-2FA

## 简短描述

动态验证码、可选界面锁与加密备份。

## 完整描述 — Chrome、Edge、Firefox

使用 Authenticator-For-2FA，在浏览器中生成和管理双重验证所需的动态验证码。

• 在设备上生成 TOTP、HOTP 和 Steam 验证码。
• 手动添加账户，或导入 OTP 链接、二维码图片、迁移二维码及支持的备份。
• 授权后，从选定网页区域、屏幕或摄像头扫描二维码。
• 搜索、收藏和调整账户顺序，点击验证码即可复制。
• 可选填入指定验证码输入框，不会提交表单。启用输入框菜单时请求网站访问权限。
• 导出密码保护的加密备份，也可明确选择明文格式。
• 可选使用独立恢复密钥，通过浏览器同步服务同步加密账户副本；各设备需使用同一浏览器同步账户。
• 可选设置界面密码。通行密钥依赖浏览器和系统支持；支持的 Mac 使用 Touch ID 时需先配置本机辅助程序。

请注意：界面锁不会加密本地账户密钥及本地同步恢复密钥，初始状态不启用密码保护。请保护浏览器配置文件，保留经过验证的备份及各服务的备用恢复方式。

二维码使用内置代码在本机解码，无广告或使用分析。可选的时间校准会在网站授权后连接 Google；可选的加密同步使用浏览器厂商服务；网页填充会把选定验证码发送到目标网站。数据处理和删除方式（包括保留的账户删除记录）请见隐私政策。

支持与隐私联系：support@macseek.cc
